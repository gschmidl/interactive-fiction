# House Adventure (NEC PC-8001, 1983)

*HOUSE ADVENTURE* version 1.2 (19 June 1983) by PC Penguins (J.M & H.M), a Japanese graphic
adventure set in a house, in N-BASIC for the NEC PC-8001 / PC-8001mkII, printed as a type-in in
*マイコン* (My Computer), October 1983. Recovered from the magazine pages. It runs in a PC-8001 emulator; no emulator is included.

## Command line

The tape has no parameters: in N-BASIC, `CLOAD` the tape and `RUN`.

## Recommended start

In a PC-8001 emulator: mount `House Adventure.cmt` as the tape, then `CLOAD` and `RUN`.
