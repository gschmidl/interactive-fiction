# Memo Satsujin (Sharp MZ-80K)

*メモ殺人* ("Memo Murder"), a Japanese graphic adventure in BASIC for the Sharp MZ-80K and MZ-1200:
MZ's friend TRS has been murdered, and MZ visits the house to find the memo TRS wrote naming the
culprit. Recovered from a magazine type-in listing, its screen pictures checked against the
machine's own character set. The tape image carries the program together with SP-5030A BASIC, so
loading it starts the game, and the game starts again when it ends. It runs in an MZ-80K emulator; no
emulator is included.

## Command line

The tape has no parameters: type `LOAD` at the monitor's `*` prompt (`L` on an MZ-700) and the game starts.

## Recommended start

In EmuZ-80K: load `Memo Satsujin.mzt` as the cassette and type `LOAD` at the monitor prompt.
