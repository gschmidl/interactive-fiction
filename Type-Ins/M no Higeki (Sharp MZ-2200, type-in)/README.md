# M no Higeki (Sharp MZ-2200)

*ミステリー << Mの悲劇 >>* ("The Tragedy of M"), a Japanese mystery adventure with graphics by Chiaki
Kasahara, in BASIC for the Sharp MZ-2000 / MZ-2200, recovered from a magazine type-in listing.
Commands are typed in two parts (COMMAND1, COMMAND2). It is a BASIC program file, so the machine's
BASIC has to be running first. It runs in an MZ-2000/MZ-2200 emulator; no emulator is included.

## Command line

The tape has no parameters: boot the MZ-2200's BASIC, then `LOAD` the tape and `RUN`.

## Recommended start

In an MZ-2200 emulator with its BASIC booted: mount `M no Higeki.mzt` as the cassette, `LOAD`, then
`RUN`.
