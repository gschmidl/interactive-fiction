# Iroha Uta no Nazo (Sharp MZ-80B, 1983)

*いろは歌の謎* ("The Riddle of the Iroha Poem") by Chiaki Kasahara, a Japanese adventure in BASIC for the
Sharp MZ-2000 / MZ-2200 with graphics RAM, printed as a type-in in *Oh!MZ*, August 1983; recovered
from the magazine pages. This tape image has the magazine's MZ-80B form of line 20, so it runs on the
MZ-80B. It is a BASIC program file, so the machine's BASIC has to be running first. It runs in an
MZ-80B emulator; no emulator is included.

## Command line

The tape has no parameters: boot the MZ-80B's BASIC, then `LOAD` the tape and `RUN`.

## Recommended start

In an MZ-80B emulator with its BASIC booted: mount `Iroha Uta no Nazo.mzt` as the cassette, `LOAD`,
then `RUN`.
