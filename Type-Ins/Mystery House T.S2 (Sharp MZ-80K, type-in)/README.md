# Mystery House T.S2 (Sharp MZ-80K, 1983)

*MYSTERY HOUSE T.S* sequel, version 1.3 of 29 March 1983 by T. Shimoyama, a Japanese graphic adventure
in BASIC for the Sharp MZ-80K, MZ-1200 and MZ-700: find the three diamonds hidden in the house and
get out; the escape screen shows how long you took. Commands are verbs in capitals (`GO MOVE TAKE
OPEN PUSH SHAKE KICK HELP LIST`); `GO` asks for one of the numbers drawn on the screen. Recovered from
a magazine type-in listing. The tape image carries the program together with its BASIC, so loading it
starts the game. It runs in an MZ-80K emulator; no emulator is included.

## Command line

The tape has no parameters: type `LOAD` at the monitor's `*` prompt (`L` on an MZ-700) and the game starts.

## Recommended start

In EmuZ-80K: load `Mystery House T.S2.mzt` as the cassette and type `LOAD` at the monitor prompt.
