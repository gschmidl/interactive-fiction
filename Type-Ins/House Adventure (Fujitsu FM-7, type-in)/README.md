# House Adventure (Fujitsu FM-7, 1983)

*HOUSE ADVENTURE* version 1.2 (14 October 1983), programmed by H. Kawaguchi and Tankentai for the
Fujitsu FM-7 / FM-8 in F-BASIC: a Japanese graphic adventure set in a house, converted from PC
Penguins' PC-8001 game, printed as a type-in in *マイコン* (My Computer), December 1983. Recovered from
the magazine pages. It runs in an FM-7 emulator; no emulator is included.

## Command line

The tape has no parameters: in F-BASIC, `LOAD` the tape and `RUN`.

## Recommended start

In XM7: mount `House Adventure.t77` as the tape, then `LOAD` and `RUN`.
