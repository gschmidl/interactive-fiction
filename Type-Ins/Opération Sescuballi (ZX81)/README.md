# Opération Sescuballi (ZX81, 1982)

*Opération "Sescuballi"*, a French text adventure by Philippe Fassier for the ZX81 with the 16K
extension, printed as a type-in in *Casus Belli* no. 11 (1982): on a moonless night you have dropped
into the grounds of the secret-service building without your equipment, and must recover the
microfilms from the safe before the guards come at 22:10. Commands are French words
("OUVRE" - "Quoi donc ?" - "PORTE"). The finished game as a tape image, in two formats, that starts
itself when loaded. It runs in any ZX81 emulator; no emulator is included.

## Command line

The tape has no parameters: on a 16K ZX81, `LOAD "SESCUBALLI"` (or let the emulator load the `.p`
file) and the game starts on its own. Never type `RUN`: it would clear the tables the game keeps in
its variables.

## Recommended start

Open `Sescuballi (finished, auto-starts).p` (or the `.tzx`) in a ZX81 emulator set to 16K, such as
EightyOne.
