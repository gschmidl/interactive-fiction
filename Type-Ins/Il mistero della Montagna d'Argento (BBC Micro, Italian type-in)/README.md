# Il mistero della Montagna d'Argento (BBC Micro)

The Italian edition of Usborne's *The Mystery of the Silver Mountain* by Chris Oxlade and Judy
Tatchell, translated by Paolo Agostini: a type-in adventure from the book, in which you start at a
crossroads and search for the Pietra del Destino, with puzzles whose clues are hidden in the book's
pages. Recovered from a scan of the book as a self-booting BBC Micro disc. As printed the listing
could not run; the disc has the book's typos and typesetting slips corrected, and one fix that lets
every game be won (the third magic word could be unreachable). Commands are two Italian words
(`PRENDI PANE`); directions are single letters `N E S O A B`; `REGISTRARE` saves to the disc. It runs
in any BBC Micro emulator; no emulator is included.

## Command line

The disc has no parameters: a BBC Model B with Acorn DFS, disc in drive 0, SHIFT+BREAK boots it.

## Recommended start

In BeebEm: File > Load Disc 0 with `MONTAGNA.ssd`, then SHIFT+F12.
