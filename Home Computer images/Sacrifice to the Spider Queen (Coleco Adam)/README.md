# Sacrifice to the Spider Queen (Coleco Adam, 1985)

*Sacrifice to the Spider Queen*, a 1985 adventure game for the Coleco Adam, on two floppy disk
images: a boot disk and the game disk. It runs in an Adam emulator; no emulator is included.

## Command line

The disks have no parameters. Put `boot.dsk` in the first disk drive and
`sacrifice_to_the_spider_queen.dsk` in the second, and start the machine from the boot disk.

## Recommended start

In ADAM+ (ADAMP_EMU): `ADAMP_EMU.exe boot.dsk sacrifice_to_the_spider_queen.dsk`
