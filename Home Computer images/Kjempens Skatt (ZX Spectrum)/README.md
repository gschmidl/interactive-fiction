# Kjempens skatt (ZX Spectrum)

*Kjempens skatt* ("The Giant's Treasure"), a Norwegian text adventure in BASIC for the 48K ZX
Spectrum by Endre Danilojj, printed as a type-in listing in a Norwegian computer magazine; recovered
from the scanned pages. The tape image has the one bug of the listing fixed: the king's riddle is now
chosen at random from all five, where the printed program always asked the same one. It runs in any
ZX Spectrum emulator; no emulator is included.

## Command line

The tape image has no parameters; it starts itself when loaded (`LOAD ""`) on a 48K Spectrum.

## Recommended start

In Fuse: `fuse --machine 48 --auto-load --tape kjempens-skatt-fixed.tap`
