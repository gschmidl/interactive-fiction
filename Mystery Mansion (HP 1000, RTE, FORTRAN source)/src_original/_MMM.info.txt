      PROGRAM MMM DESCRIPTION
C     IWRD  IS USED TO STORE THE WORDS INPUT BY THE PLAYER
C     IVRB  CONTAINS THE VERBS USED IN THE GAME
C     IPRP  CONTAINS THE PREPPOSTIONS USED IN THE GAME
C     IDTN  CONTAINS THE DIRECTIONS
C     IRNM  CONTAINS THE ROOMS NAMES
C     IROM  CONTAINS THE ROOM DATA, SUCH AS THE NUMBER AND LIGHT CONDITION
C     IRSN  CONTAINS THE INHABITANTS NAMES
C     IRES  CONTAINS THE INHABITANTS DATA, SUCH AS ROOM THEY ARE IN
C     IVEN  CONTAINS THE DATA ON THE ITEMS USED IN THE GAME
C     IXT   CONTAINS THE EXIT DATA SUCH AS ROOM TO ROOM AND DOOR CONDITION
C     ICLS  CONTAINS THE CLASSES OF PLAYERS
C     ITST  CONTAINS A VARIETY OF TESTING DATA SUCH AS TURN AND ROOM
C     NAME  CONTAINS THE NAME OF THE SEGMENT BEING CALLED
C     IPR   CONTAINS THE DATA FROM RMPAR
C     RND   CONTAINS A RANDOM NUMBER
C     NTAG  CONTAINS THE NAME OF THE PLAYER
C     IWP   CONTAINS THE NAME OF THE MURDER WEAPON
C

C

C

C

C
C  -MMSF-  PAGES F-1 TO F-16  LOW NUMBERED VERBS SEGMENT
C
C      QUIT  STOP  SCORE  GET  TAKE  DROP  GIVE  LOOK  READ  FIND
C      LIST  LIGHT  TURN  HELP  OPEN  CLOSE  SNUFF  BLOW

C      KILL  SUSPEND  RESTORE  DRINK  MYSTERY  QUESTION  LISTEN
