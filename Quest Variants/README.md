# Quest Variants

- [Quest (Data General MV, AOS-VS)](Quest%20%28Data%20General%20MV%2C%20AOS-VS%29/) - *Quest*, a multiplayer role-playing game from the NADGUG tape, for up to ten players.
- [Quest (Philips P7000, Four-Phase MFE, multiplayer)](Quest%20%28Philips%20P7000%2C%20Four-Phase%20MFE%2C%20multiplayer%29/) - QUEST version 1, a multi-player cave game in Pascal from a Danish site, for up to six players.
- [Quest (VAX VMS, DECUS, full source)](Quest%20%28VAX%20VMS%2C%20DECUS%2C%20full%20source%29/) - Ball State University's QUEST 3.36 (1985), a dungeon crawler of six dungeons with permanent death.
- [Quest 1984 (Data General MV, AOS-VS)](Quest%201984%20%28Data%20General%20MV%2C%20AOS-VS%29/) - An earlier *Quest*, as it was being written in 1984, with its authors' own characters.
