# The Sewers of Piing Poong

A tiny early-1980s text adventure written in TECO - DEC's text editor, used as a programming
language - searching a flat-file database of 38 rooms: sewers, catacombs, a pipe maze, a rat and a
manhole that is the only way out. Found among a batch of DEC magtape images. `Sewer.exe` is a
Python port of the decoded TECO engine with the original database. Verbs `MOVE <direction>`, `TAKE`,
`DROP`, `LOOK`, `INVENTORY` and `OPEN` abbreviate to their first letter (`M E`); `QUIT` was added.

## Command line

`Sewer.exe` takes no parameters.

## Recommended start

`Sewer.exe`
