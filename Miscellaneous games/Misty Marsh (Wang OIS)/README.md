# Misty Marsh (Wang OIS)

*Misty Marsh*, a cave adventure written not as a program but as a Wang word processor **glossary**:
a keystroke macro that types the story at you, reads your answer back out of the document and jumps
to another entry depending on what it finds. `misty.exe` runs that glossary, taken unmodified from
the Wang disk. Type an answer and press Enter; a blank line is EXECUTE. The line in brackets is the
workstation's prompt line, where the game taunts you.

## Command line

`misty.exe` takes no parameters.

## Recommended start

`misty.exe`
