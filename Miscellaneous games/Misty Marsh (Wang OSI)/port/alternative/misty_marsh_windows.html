Restoration notes

This is a clean-room gameplay port reconstructed from the text and branch data recoverable from the supplied Wang image. Wang-specific document/glossary mechanics were replaced with a normal command interface. The original image contains duplicated/variant records and some damaged compiler-era score state; this port preserves the recovered scenes, puzzles, inventory dependencies, fatal branches, and a 100-point treasure score.
