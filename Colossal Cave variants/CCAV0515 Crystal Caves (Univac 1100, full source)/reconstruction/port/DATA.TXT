   SECTION 4: TRAVEL TABLE.
      EACH LINE CONTAINS A THREE-DIGIT LOCATION NUMBER (X), A SPACE,
      A NINE-DIGIT MOTION CODE OR LOCATION NUMBER (Y), A SPACE, AND A
      LIST OF FIVE-CHARACTER MOTION VERBS (SEE SECTION 3) SEPARATED BY
      SPACES.
      NOTE THAT A MOTION VERB OF '1' CAUSES FORCED MOTION!
      THE DESTINATION NUMBER (Y) IS A SIGNED VALUE WITH THE (UNSIGNED)
      DECIMAL DIGIT FORMAT:     MVNNNLLL

      IF THE VALUE IS NEGATIVE, THEN THIS TEST IS USED IN CONJUNCTION
      WITH THE FOLLOWING *DIFFERENT* DESTINATION NUMBER.  THIS IS USEFUL
      FOR DESCRIBING MOTIONS WHICH ONLY OCCUR WHEN TWO OR MORE
      CONDITIONS ARE MET.  IF THE DESTINATION CODE (SEE LLL BELOW)
      SPECIFIES A LOCATION, IT IS IGNORED.  IF IT SPECIFIES A MESSAGE,
      THEN THE MESSAGE IS PRINTED (IF THE CONDITION IS MET) *AND* THE
      NEXT DIFFERENT DESTINATION IS CONSIDERED.

      THE INTERPRETATION OF THE UNSIGNED PART OF THE DESTINATION IS:

      LLL IS THE DESTINATION:
              LLL<300 IS REAL PLACE
              300<LLL<500 IS SPECIAL LLLXX CODE
              500<LLL IS MESSAGE TO OUTPUT INSTEAD OF GOING SOMEPLACE
      MEANWHILE, M SPECIFIES THE CONDITIONS ON THE MOTION.
              M       V       NNN
              0       0       0       UNCONDITIONAL TRANSFER
                      0       1-100   DO WITH NNN PROBABILITY
                      1       ---     AS ABOVE, BUT FORBIDDEN TO DWARVES
              1       -       NNN     MUST BE CARRYING OBJECT NNN
              2       -       NNN     MUST *NOT* BE CARRYING OBJECT NNN
              3       -       NNN     MUST BE IN PRESENCE (HOLDING OR IN
                                      SAME ROOM) AS NNN
              4       -       NNN     MUST *NOT* BE IN PRESENCE OF
                                      OBJECT NNN
              5       V       NNN     PROP(NNN) MUST .EQ. V
              6       V       NNN     PROP(NNN) MUST *NOT* .EQ. V
      IF THE CONDITION (IF ANY) IS NOT MET, THEN THE NEXT *DIFFERENT*
      "DESTINATION" VALUE IS USED (UNLESS IT FAILS TO MEET *ITS*
      CONDITIONS, IN WHICH CASE THE NEXT IS FOUND, ETC.).  TYPICALLY,
      THE NEXT DEST WILL BE FOR ONE OF THE SAME VERBS, SO THAT ITS ONLY
      USE IS AS THE ALTERNATE DESTINATION FOR THOSE VERBS.
      FOR INSTANCE:
              15  10010022 NORTH UP    NE    SHAFT
              15        14 NORTH
      THIS SAYS THAT, FROM LOC 15, ANY OF THE VERBS "NORTH", "UP", ETC.,
      WILL TAKE HIM TO 22 IF HE'S CARRYING OBJECT 10, AND OTHERWISE WILL
      GO TO 14.
              11  54003008 UPSTR
              11         9 UP
      THIS SAYS THAT, FROM 11, "UPSTREAM" TAKES HIM TO 8 UNLESS
      PROP(3)=4, IN WHICH CASE HE GOES TO 9.  VERB "UP" TAKES HIM TO 9
      REGARDLESS OF PROP(3).
              43      -611 JUMP
              43  00080046 JUMP
              43        28 CLIMB
      IN THIS EXAMPLE, SAYING "JUMP" AT LOCATION 43 CAUSES MESSAGE 111
      TO BE OUTPUT, AND THEN AN 80% PROBABILITY TRANSFER TO LOCATION 46.
      IF THIS FAILS, OR IF HE SAYS "CLIMB" INSTEAD, HE ENDS UP AT
      LOCATION 28.  NOTE THAT FOR "JUMP", HE GETS BOTH MESSAGE AND MOVE!
