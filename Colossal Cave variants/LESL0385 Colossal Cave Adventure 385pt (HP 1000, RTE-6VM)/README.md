# Adventure, 385 points (HP 1000)

The 385-point *Adventure* that Bruce G. Leslie ("Beasley") adapted for HP 1000 minicomputers at
Haystack Observatory in 1978-79 and gave to the HP 1000 users group's contributed software library.
A plain late-1970s Crowther and Woods game with 35 extra points: no SAVE, no hints, no maintenance
mode. Native Windows console port of the FORTRAN.

## Command line

`adven.exe` takes no parameters. It reads the database `#ADVZZ` and writes its work file `#ADVXX` in
the current directory, so start it in the folder that holds `#ADVZZ`.

## Recommended start

`adven.exe`, started in its own folder (double-clicking it does that).
