# ПРИКЛЮЧЕНИЕ (Colossal Cave Adventure, 340 points, Russian)

A Russian 340-point *Adventure* written in C for DEMOS, the Soviet Unix, around 1984-85. It is a
reimplementation, not a translation of the FORTRAN: the cave is written in a small description
language and compiled into the three data files the game reads. All text is Russian (`да`, `вниз`,
`возьми лампу`, `помоги`, `сохрани`). Native Windows port.

## Command line

`adventure.exe` takes no parameters. Two launchers pick the wording:

| Launcher | Wording |
| --- | --- |
| `run.bat` | the 1985 text as archived, typos included |
| `play-revised-text.bat` | the proof-read text of the later Linux build (same map, puzzles and scoring) |

## Recommended start

`play-revised-text.bat`
