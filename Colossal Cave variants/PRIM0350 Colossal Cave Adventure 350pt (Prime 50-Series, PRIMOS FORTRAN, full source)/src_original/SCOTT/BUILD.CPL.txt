/* BUILD.CPL -- CPL FILE FOR BUILDING "ADVENTURE"
/* WRITTEN BY: SCOTT FABBRI (NOVEMBER 1983)
&SEVERITY &ERROR &ROUTINE BOMB_OUT
&DEBUG &ECHO COM
COMO BUILD.COMO
/* COMPILE AND LOAD "ADVENTURE"
/*
/* COMPILE
LISTING ADVENTURE.LIST
BINARY  ADVENTURE.BIN
FTN ADVENTURE.FTN -64V -INTL -B YES -L YES
CLOSE ADVENTURE.BIN
BINARY ADVSUB.BIN
FTN ADVSUB.FTN    -64V -INTL -B YES -L YES
CLOSE ADVSUB.BIN
CLOSE ADVENTURE.LIST
/*
/* LOAD
/*
&DATA SEG
LOAD #ADV
COMMON ABS 4001
SPLIT 70000
S/LOAD ADVENTURE.BIN 0 4000 4000
D/LOAD ADVSUB.BIN
D/LIB VAPPLB
D/LIB
MAP 6
SAVE
MAP ADVENTURE.MAP
RETURN
SHARE
AD
DELETE #ADV
QUIT
&END
&DATA M SMFABB -NOW
ADVENTURE has been reloaded.
&END
&RETURN &MESSAGE All done.
&ROUTINE BOMB_OUT
&SEVERITY &ERROR &IGNORE
&DATA M SMFABB -NOW
Something went wrong with the recompilation!  Check the file.
&END
&STOP 1 &MESSAGE BOO!
