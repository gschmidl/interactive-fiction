(0084)  C  FORCED(LOC)  = TRUE IF LOC MOVES WITHOUT ASKING FOR INPUT (COND=2)
(0085)  C  DARK(DUMMY)  = TRUE IF LOCATION "LOC" IS DARK

(0169)  C  DESCRIPTION OF THE DATABASE FORMAT
(0170)  C
(0171)  C
(0172)  C  THE DATA FILE CONTAINS SEVERAL SECTIONS.  EACH BEGINS WITH A LINE CONTAINING
(0173)  C  A NUMBER IDENTIFYING THE SECTION, AND ENDS WITH A LINE CONTAINING "-1".
(0174)  C
(0175)  C  SECTION 1: LONG FORM DESCRIPTIONS.  EACH LINE CONTAINS A LOCATION NUMBER,
(0176)  C       A TAB, AND A LINE OF TEXT.  THE SET OF (NECESSARILY ADJACENT) LINES
(0177)  C       WHOSE NUMBERS ARE X FORM THE LONG DESCRIPTION OF LOCATION X.
(0178)  C  SECTION 2: SHORT FORM DESCRIPTIONS.  SAME FORMAT AS LONG FORM.  NOT ALL
(0179)  C       PLACES HAVE SHORT DESCRIPTIONS.
(0180)  C  SECTION 3: TRAVEL TABLE.  EACH LINE CONTAINS A LOCATION NUMBER (X), A SECOND
(0181)  C       LOCATION NUMBER (Y), AND A LIST OF MOTION NUMBERS (SEE SECTION 4).
(0182)  C       EACH MOTION REPRESENTS A VERB WHICH WILL GO TO Y IF CURRENTLY AT X.
(0183)  C       Y, IN TURN, IS INTERPRETED AS FOLLOWS.  LET M=Y/1000, N=Y MOD 1000.
(0184)  C               IF N<=300       IT IS THE LOCATION TO GO TO.
(0185)  C               IF 300<N<=500   N-300 IS USED IN A COMPUTED GOTO TO
(0186)  C                                       A SECTION OF SPECIAL CODE.
(0187)  C               IF N>500        MESSAGE N-500 FROM SECTION 6 IS PRINTED,
(0188)  C                                       AND HE STAYS WHEREVER HE IS.
(0189)  C       MEANWHILE, M SPECIFIES THE CONDITIONS ON THE MOTION.
(0190)  C               IF M=0          IT'S UNCONDITIONAL.
(0191)  C               IF 0<M<100      IT IS DONE WITH M% PROBABILITY.
(0192)  C               IF M=100        UNCONDITIONAL, BUT FORBIDDEN TO DWARVES.
(0193)  C               IF 100<M<=200   HE MUST BE CARRYING OBJECT M-100.
(0194)  C               IF 200<M<=300   MUST BE CARRYING OR IN SAME ROOM AS M-200.
(0195)  C               IF 300<M<=400   PROP(M MOD 100) MUST *NOT* BE 0.
(0196)  C               IF 400<M<=500   PROP(M MOD 100) MUST *NOT* BE 1.
(0197)  C               IF 500<M<=600   PROP(M MOD 100) MUST *NOT* BE 2, ETC.
(0198)  C       IF THE CONDITION (IF ANY) IS NOT MET, THEN THE NEXT *DIFFERENT*
(0199)  C       "DESTINATION" VALUE IS USED (UNLESS IT FAILS TO MEET *ITS* CONDITIONS,
(0200)  C       IN WHICH CASE THE NEXT IS FOUND, ETC.).  TYPICALLY, THE NEXT DEST WILL
(0201)  C       BE FOR ONE OF THE SAME VERBS, SO THAT ITS ONLY USE IS AS THE ALTERNATE
(0202)  C       DESTINATION FOR THOSE VERBS.  FOR INSTANCE:
(0203)  C               15      110022  29      31      34      35      23      43
(0204)  C               15      14      29
(0205)  C       THIS SAYS THAT, FROM LOC 15, ANY OF THE VERBS 29, 31, ETC., WILL TAKE
(0206)  C       HIM TO 22 IF HE'S CARRYING OBJECT 10, AND OTHERWISE WILL GO TO 14.
(0207)  C               11      303008  49
(0208)  C               11      9       50
(0209)  C       THIS SAYS THAT, FROM 11, 49 TAKES HIM TO 8 UNLESS PROP(3)=0, IN WHICH
(0210)  C       CASE HE GOES TO 9.  VERB 50 TAKES HIM TO 9 REGARDLESS OF PROP(3).
(0211)  C  SECTION 4: VOCABULARY.  EACH LINE CONTAINS A NUMBER (N), A TAB, AND A
(0212)  C       FIVE-LETTER WORD.  CALL M=N/1000.  IF M=0, THEN THE WORD IS A MOTION
(0213)  C       VERB FOR USE IN TRAVELLING (SEE SECTION 3).  ELSE, IF M=1, THE WORD IS
(0214)  C       AN OBJECT.  ELSE, IF M=2, THE WORD IS AN ACTION VERB (SUCH AS "CARRY"
(0215)  C       OR "ATTACK").  ELSE, IF M=3, THE WORD IS A SPECIAL CASE VERB (SUCH AS
(0216)  C       "DIG") AND N MOD 1000 IS AN INDEX INTO SECTION 6.  OBJECTS FROM 50 TO
(0217)  C       (CURRENTLY, ANYWAY) 79 ARE CONSIDERED TREASURES (FOR PIRATE, CLOSEOUT).
(0218)  C  SECTION 5: OBJECT DESCRIPTIONS.  EACH LINE CONTAINS A NUMBER (N), A TAB,
(0219)  C       AND A MESSAGE.  IF N IS FROM 1 TO 100, THE MESSAGE IS THE "INVENTORY"
(0220)  C       MESSAGE FOR OBJECT N.  OTHERWISE, N SHOULD BE 000, 100, 200, ETC., AND
(0221)  C       THE MESSAGE SHOULD BE THE DESCRIPTION OF THE PRECEDING OBJECT WHEN ITS
(0222)  C       PROP VALUE IS N/100.  THE N/100 IS USED ONLY TO DISTINGUISH MULTIPLE
(0223)  C       MESSAGES FROM MULTI-LINE MESSAGES; THE PROP INFO ACTUALLY REQUIRES ALL
(0224)  C       MESSAGES FOR AN OBJECT TO BE PRESENT AND CONSECUTIVE.  PROPERTIES WHICH
(0225)  C       PRODUCE NO MESSAGE SHOULD BE GIVEN THE MESSAGE ">$<".
(0226)  C  SECTION 6: ARBITRARY MESSAGES.  SAME FORMAT AS SECTIONS 1, 2, AND 5, EXCEPT
(0227)  C       THE NUMBERS BEAR NO RELATION TO ANYTHING (EXCEPT FOR SPECIAL VERBS
(0228)  C       IN SECTION 4).
(0229)  C  SECTION 7: OBJECT LOCATIONS.  EACH LINE CONTAINS AN OBJECT NUMBER AND ITS
(0230)  C       INITIAL LOCATION (ZERO (OR OMITTED) IF NONE).  IF THE OBJECT IS
(0231)  C       IMMOVABLE, THE LOCATION IS FOLLOWED BY A "-1".  IF IT HAS TWO LOCATIONS
(0232)  C       (E.G. THE GRATE) THE FIRST LOCATION IS FOLLOWED WITH THE SECOND, AND
(0233)  C       THE OBJECT IS ASSUMED TO BE IMMOVABLE.
(0234)  C  SECTION 8: ACTION DEFAULTS.  EACH LINE CONTAINS AN "ACTION-VERB" NUMBER AND
(0235)  C       THE INDEX (IN SECTION 6) OF THE DEFAULT MESSAGE FOR THE VERB.
(0236)  C  SECTION 9: LIQUID ASSETS, ETC.  EACH LINE CONTAINS A NUMBER (N) AND UP TO 20
(0237)  C       LOCATION NUMBERS.  BIT N (WHERE 0 IS THE UNITS BIT) IS SET IN COND(LOC)
(0238)  C       FOR EACH LOC GIVEN.  THE COND BITS CURRENTLY ASSIGNED ARE:
(0239)  C               0       LIGHT
(0240)  C               1       IF BIT 2 IS ON: ON FOR OIL, OFF FOR WATER
(0241)  C               2       LIQUID ASSET, SEE BIT 1
(0242)  C               3       PIRATE DOESN'T GO HERE UNLESS FOLLOWING PLAYER
(0243)  C       OTHER BITS ARE USED TO INDICATE AREAS OF INTEREST TO "HINT" ROUTINES:
(0244)  C               4       TRYING TO GET INTO CAVE
(0245)  C               5       TRYING TO CATCH BIRD
(0246)  C               6       TRYING TO DEAL WITH SNAKE
(0247)  C               7       LOST IN MAZE
(0248)  C               8       PONDERING DARK ROOM
(0249)  C               9       AT WITT'S END
(0250)  C       COND(LOC) IS SET TO 2, OVERRIDING ALL OTHER BITS, IF LOC HAS FORCED
(0251)  C       MOTION.
(0252)  C  SECTION 10: CLASS MESSAGES.  EACH LINE CONTAINS A NUMBER (N), A TAB, AND A
(0253)  C       MESSAGE DESCRIBING A CLASSIFICATION OF PLAYER.  THE SCORING SECTION
(0254)  C       SELECTS THE APPROPRIATE MESSAGE, WHERE EACH MESSAGE IS CONSIDERED TO
(0255)  C       APPLY TO PLAYERS WHOSE SCORES ARE HIGHER THAN THE PREVIOUS N BUT NOT
(0256)  C       HIGHER THAN THIS N.  NOTE THAT THESE SCORES PROBABLY CHANGE WITH EVERY
(0257)  C       MODIFICATION (AND PARTICULARLY EXPANSION) OF THE PROGRAM.
(0258)  C  SECTION 11: HINTS.  EACH LINE CONTAINS A HINT NUMBER (CORRESPONDING TO A
(0259)  C       COND BIT, SEE SECTION 9), THE NUMBER OF TURNS HE MUST BE AT THE RIGHT
(0260)  C       LOC(S) BEFORE TRIGGERING THE HINT, THE POINTS DEDUCTED FOR TAKING THE
(0261)  C       HINT, THE MESSAGE NUMBER (SECTION 6) OF THE QUESTION, AND THE MESSAGE
(0262)  C       NUMBER OF THE HINT.  THESE VALUES ARE STASHED IN THE "HINTS" ARRAY.
(0263)  C       HNTMAX IS SET TO THE MAX HINT NUMBER (<= HNTSIZ).  NUMBERS 1-3 ARE
(0264)  C       UNUSABLE SINCE COND BITS ARE OTHERWISE ASSIGNED, SO 2 IS USED TO
(0265)  C       REMEMBER IF HE'S READ THE CLUE IN THE REPOSITORY, AND 3 IS USED TO
(0266)  C       REMEMBER WHETHER HE ASKED FOR INSTRUCTIONS (GETS MORE TURNS, BUT LOSES
(0267)  C       POINTS).
(0268)  C  SECTION 12: MAGIC MESSAGES. IDENTICAL TO SECTION 6 EXCEPT PUT IN A SEPARATE
(0269)  C       SECTION FOR EASIER REFERENCE.  MAGIC MESSAGES ARE USED BY THE STARTUP,
(0270)  C       MAINTENANCE MODE, AND RELATED ROUTINES.
(0271)  C  SECTION 0: END OF DATABASE.
