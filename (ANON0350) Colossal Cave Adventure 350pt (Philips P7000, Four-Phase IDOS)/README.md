# Colossal Cave Adventure 350pt - Philips P7000 (Four-Phase), IDOS

**Status: STAGED 2026-09-19 - not ported, nothing built.** Files here are verified copies (md5) of the originals named below.

Same tape as `Quest (Philips P7000, Four-Phase MFE, multiplayer)`; read that README for the tape layout.

Adventure is a compiled FORTRAN build of the 350-point game with the wizard/hours machinery:
text at ~870000-915000 of the concatenated payload (`WELCOME TO ADVENTURE!!`, class messages up to `ADVENTURER
GRANDMASTER`), FORMATs at ~990046 (`IF YOU WERE TO QUIT NOW, YOU WOULD SCORE ... OUT OF A POSSIBLE`). Several copies of the
text are present (16 x "COLOSSAL CAVE"). Binary only; needs the same emulator as QUEST, under IDOS rather than MFE.
