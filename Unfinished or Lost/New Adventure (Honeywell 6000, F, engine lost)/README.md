# New Adventure (Mark D. Niemiec, Waterloo, 1979)

Mark D. Niemiec's *New Adventure* (University of Waterloo, 1979), written in his own language F for
the Honeywell 6000, on top of a 1977 Waterloo port of Crowther and Woods' *Adventure*. The game's
source survives but the F engine that ran it and the compiled game are lost, so it cannot be played
as a game. `newadv.exe` walks its 162 recovered locations, using only the original text and exits,
and shows the F source behind anything it will not simulate (`src`); `help` lists its commands.

## Command line

`newadv.exe [-e]`

| Option | Effect |
| --- | --- |
| `-e` | echo the commands (for scripted demonstrations) |

## Recommended start

`newadv.exe`
