# Unfinished or Lost

- [Martian Adventure (Honeywell 6000, B, unfinished)](Martian%20Adventure%20%28Honeywell%206000%2C%20B%2C%20unfinished%29/) - Brad Templeton's unfinished Martian adventure (Waterloo, 1978-79), playable in part.
- [New Adventure (Honeywell 6000, F, engine lost)](New%20Adventure%20%28Honeywell%206000%2C%20F%2C%20engine%20lost%29/) - Mark Niemiec's *New Adventure* (Waterloo, 1979), whose engine is lost; its 162 locations can be walked.
- [Underground (Scans)](Underground%20%28Scans%29/) - Gary Kleppe's UNDERGROUND (1979), a BASIC-PLUS cave adventure recovered from scanned listings.
