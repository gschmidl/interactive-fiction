# The Monastery — native Windows port

An unfinished text adventure written in Tymshare TYMCOM-X BASIC for a PDP-10,
dated 8–9 January 1987, recovered from the `novafield` Tymshare tape. It has no
title in the source; "The Monastery" is a working title from the setting.

You arrive at a ruined monastery built against a mountain in a crater-shaped
depression. Inside are a burned library, a cathedral with a headless statue and
a blood-stained sacrificial altar, two secret doors, a wandering ghoul, a
zombie, a light-fingered hobbit, a dwarf — and, behind the statue, a dusty
wooden room with the words `SAIRE SUBDIR` on the wall.

    bin\monastery.exe

## Building

Needs a C99 compiler; built and tested with the mingw-w64 gcc 15.2 that ships
with Strawberry Perl.

```bash
make
```

or directly:

```bash
gcc -std=c99 -Wall -Wextra -O2 -o bin/monastery.exe src/monastery.c src/basic.c -lm
```

The `.exe` is self-contained — `TEXT.GME` is embedded — and needs no runtime
files beyond a character file it will offer to create.

## Playing

```
monastery.exe [--char NAME] [--text FILE] [--seed N] [--strict]
```

| option | effect |
|--------|--------|
| `--char NAME` | load `NAME.GME` instead of asking for a name |
| `--text FILE` | read room text from `FILE` instead of the built-in copy |
| `--seed N` | fix the random seed, for reproducible transcripts |
| `--strict` | leave `QUIT` inert, exactly as the 1987 source had it |

As in the original, a `TEXT.GME` in the working directory is picked up
automatically if there is one; otherwise the embedded copy is used.

The program asks for a character name and loads `NAME.GME`. If there is no such
file it rolls one up and saves it, so you can carry a character between
sessions.

The prompt is `]`. It changes to `*` when a monster has you in combat, and only
combat verbs work until you kill it, knock it out, or `DISENGAGE`.

Useful commands:

```
LOOK                                    INVENTORY
GET SWORD            DROP SWORD         PUT THE ROCK IN THE POUCH
WEAR THE BACKPACK    STRAP ON SWORD     PUT SWORD IN RIGHT HAND
OPEN NORTH DOOR      CLOSE EAST DOOR    MOVE THE STATUE
SEARCH THE TABLE     SEARCH THE GHOUL
SEARCH FOR A SECRET DOOR ON THE NORTH WALL
SEARCH THE NORTH WALL FOR A SECRET DOOR
ENGAGE THE GHOUL     ATTACK   PUMMEL   GRAPPLE   DISENGAGE
CHARACTER            N S E W NE NW SE SW UP DOWN
```

`ATTACK`, `PUMMEL` and `GRAPPLE` only work once you are in combat. Outside it,
`ENGAGE <monster>` starts a fight. Note that armed attacks take a monster down
one hit point at a time — that is an original bug, not a port bug, and
`PUMMEL` and `GRAPPLE` do far more damage.

`--strict` aside, dying is the only way the 1987 program ever ended.

## What this is

`src/monastery.c` is a line-by-line transliteration of `SAVE.TBA`, not a
rewrite. Every `DEFINE` is a function, every `GOTO` is a `goto`, and the
original line numbers survive as labels and comments so the two can be read
side by side. All the state is global because BASIC had no locals and the
program relies on subroutines clobbering each other's variables.

`src/gamedata.h` is generated by `../work/gen_data_h.py` straight from the
`DATA` statements and from `TEXT.GME`. The 1,476 data items are consumed by the
program's own `READ` sequence with nothing left over.

The engine's own bugs are preserved and marked `[original bug]` in the source;
`docs/NOTES.md` lists all seventeen of them, along with the dialect analysis, the
data layout, and what is known about `SAIRE SUBDIR`. `docs/MAP.md` is the full
map, objects and doors, generated from the recovered tables.

## What is *not* original

Three things, and only three:

1. **The character roll-up.** `ADDPLAYER` reads a `NAME.GME` file holding six
   strings and 82 numbers. No such file and no generator for that format
   survived — `charc.tba` on the same tape writes a different layout for a
   different game, and none of its values were carried across. The roll-up in
   `monastery.c` writes a file in exactly the shape `ADDPLAYER` reads, with
   stats chosen to suit the thresholds the game actually tests (8 for strength
   and dexterity, 6 for luck; moving the cathedral statue needs strength 8).
   The stat scale and the skill ranges are a reconstruction, not recovered
   data. Supply your own `NAME.GME` if you would rather not use it.

2. **`QUIT`.** The verb and its action code are in the original vocabulary but
   nothing dispatched them. The port ends the game on `QUIT`; `--strict` puts
   it back the way it was.

3. **Room 46's two off-map exits.** North and north-west from room 46 name room
   52, in a 50-room table; the original interpreter would have stopped with a
   subscript error. The port treats them as walls.

Input is upper-cased on the way in, which is what the Tymshare terminals this
was written for would have sent anyway.

## Layout

```
src_original/   save.tba, text.gme as recovered, plus charc.tba for reference
port/src/       basic.h/.c   the slice of TYMCOM-X BASIC the program uses
                monastery.c  the transliterated game
                gamedata.h   generated tables
port/docs/      NOTES.md     dialect, data layout, the seventeen original bugs
                MAP.md       generated map, objects, doors
work/           extraction and generation scripts
```
