# Caves 2 (HP 3000)

The companion to *Caves* from the same HP 3000 games account, in BASIC/3000: "just like Caves 1,
except you set up the caves". You give each cavern up to five tunnels, then explore the caves
yourself or ask a friend to find the way out. The original MPE program is built into `Caves2.exe`,
which emulates an HP 3000 Series III and the parts of MPE the program uses.

## Command line

`Caves2.exe [options]`

| Option | Effect |
| --- | --- |
| `--about` | say what the program is |
| `-u` | set the clock's hour to 14, which lifts the opening hours of the HP 3000 games that keep them; this one keeps none |
| `--trace` | write an instruction trace to standard error |
| `-h`, `--help` | list the options |

## Recommended start

`Caves2.exe`
