# HP-3000 games

- [Caves 1 (HP 3000, MPE)](Caves%201%20%28HP%203000%2C%20MPE%29/) - Lost in the Duzzledorf Caves with your food run out: find the one path out.
- [Caves 2 (HP 3000, MPE)](Caves%202%20%28HP%203000%2C%20MPE%29/) - The companion to *Caves*: build the caves yourself, then find the way out.
- [Mystery Mansion (HP 3000, MPE)](Mystery%20Mansion%20%28HP%203000%2C%20MPE%29/) - Bill Wolpert's *Mystery Mansion* rev. 16: a murder in an old mansion, scene, culprit and weapon drawn from the clock.
- [Warp (HP 3000, MPE)](Warp%20%28HP%203000%2C%20MPE%29/) - *Warp* by Rob Lucke and Bill Frolik, a large Pascal adventure with a rich parser.
