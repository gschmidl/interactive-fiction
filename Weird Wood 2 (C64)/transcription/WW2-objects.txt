Printed list of the 66 objects, giving each object's "in room" description
(the text O$(n) / the room-listing line).  Entries with no printed text are
scenery objects that have no free-standing description; the name shown in
[brackets] is the annotator's handwritten label.

Case is AS PRINTED.  The printer inverts letter case (see WW2-OCR-notes.md),
so "tHERE IS A TORCH HERE." displays on the C64 as "There is a torch here."

BASIC listing, where the annotator wrote one.

NOTE ON THE HANDWRITTEN HANDLER NUMBERS
---------------------------------------
For objects 56-62 the handwritten numbers agree exactly with line 3314 of the
listing (ONOJ-59GOTO3600,3610,3620 -> objects 60/61/62).
For objects 50-57 the annotator's numbers sit about two rows low.  The listing
itself is self-consistent and is confirmed by the text it prints:
    3313 ONOJ-49GOTO3500,3008,3520,3008,3540,3550,3008,3570
      obj 50 control panel -> 3500 (reads WW 8.DAT, the security-control panel)
      obj 52 boat          -> 3520 ("tHE BOAT IS HALF FULL OF WATER...")
      obj 54 sausage roll  -> 3540 ("uNDER THE SAUSAGE ROLL ... 'try room 477'")
      obj 55 card          -> 3550 (prints the security-pass box)
      obj 57 bottle        -> 3570 ("tHE BOTTLE IS EMPTY.")
