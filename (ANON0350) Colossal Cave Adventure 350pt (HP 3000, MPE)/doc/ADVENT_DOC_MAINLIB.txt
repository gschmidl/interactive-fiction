    *ABST TITLE .. The Adventure Game (dwarfs, caves and treasures)

    *ABST BODY ... This is a game of exploration patterned after the
                   Hobbit.  Explore the forest and cave to find the
                   treasures and try to get them safely home.  It has
                   built-in restrictions on use during business hours
                   and can be suspended for later play.

  This game has been renamed to fit the users lib naming conventions.
  The name changes from the MAINLIB account are as follows:

      ADVENT .PUB    = ADVENTP  - Program file
      ADVENT .SOURCE = ADVENTS  - Fortran source file
      ADVENT .DATA   = ADVDATA  - Data file forms ADVCOMS, ADVLINS
      ADVENT .DOC    = ADVDOC   - Combined dcoumentation file

  The easiest way to prepare this program for use is to copy files
  That ADVENT nneds into your own GROUP and ACCOUNT. Copy:
  ADVENT.PUB to ADVENT, ADVENT.DATA to ADVDATA, Then :RUN ADVENT.
  this will cause the file ADVLINS to be created during the
  INITIALIZATION Process.

  Otherwise it is best to copy the source file ADVENT.SOURCE to
  ADVENTS and modify and compile it by using the command
  :FORTPREP ADVENTS.  When the program is compiled, the command
  :SAVE$OLDPASS,ADVENTP makes the program ready to run.  Copy
  file ADVENT.DATA to ADVDATA and :RUN ADVENTP.  This will create
  files ADVCOMS and ADVLINS through the initialization routines.

  Keep the source and data files from all players until they have
  finished the game.  If you peek at the answers it is no fun!
  Of course you should not look either unless you aren't a player.

  Other authors of this game are: Willie Crowthers, PARC-MAXC
  and Gary Palter, MIT-MULTICS.

  USER'S GUIDE TO ADVENTURE

  1.     Files on tape from which the program is produced:

       * ADVENTS - adventure source
       * ADVDATA - initialization data
       * ADVDOC  - these directions

         The following comprise the running program:

       * ADVENTP - adventure program file
       * ADVCOMS - adventure data file of game status
       * ADVLINS - adventure data file of ADV-dialog

  2.     Things you may want to change

         The COMMAND intrinsic is called to issue :FILE commands
         which locate the data files.  You may wish to specify these
         with qualified names of a different group and/or account.
         A comment line in the source is provided for these mods.
         Using EDIT3000, command /lq16/17 to access the file equations.
         You will see the MODIFY command followed by the line numbers
         of the change locations.  If you are using an HP terminal
         with an enter key, position the cursor on the line in
         question and enter it.

  3.     After modifying the source, you can stream the job file
         shown below to create the program file ADVENTP.

  4.     To initialize the adventure program, first issue the file
         command :FILE FTN01=ADVDATA,OLD
         Then :RUN ADVENTP

  5.     To change game parameters at a later date, give the restore
         command with no ADVSAVE file in the group.  This will get
         you into the WIZARD sequence which follows.  (You may also
         say MAGIC MODE at restore time to get into WIZARD sequence.)
